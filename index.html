Primary set lists

Primary only — Grades 1–5, EY1, EY2 and Minis. Builds class lists for the three subjects the PYP timetable splits a homeroom on: Arabic A/B, Islamic A/B and UAESS (Social Studies, which the timetable runs for the Arabic A cohort only). The sets themselves come from the loaded Primary XML, so the groupings are always whatever aSc currently says; the spreadsheet only decides which student goes in which one. Join key is Form against the aSc class, and School Id identifies the student. Everything is read in the browser and never uploaded or committed.

The export is one workbook with a tab per year group, each holding that year's class lists stacked one under another with the class name above each table. It is written to be read and printed, not imported. Tick sets to export only those; tick none and every class list goes in.

Toddle export

Secondary source. Writes the timetable into Toddle's import template. Pick the programme: MYP gives a sheet per subject, DP1 and DP2 a sheet per block. Load the template you downloaded from Toddle — its Hiddentimetable tab supplies the class list and ids, and the Staff cheat sheet supplies teacher emails, so the export only ever names classes and staff Toddle already knows. Three workbooks come out — Regular for classes that run the same every week, then Week A and Week B for the ones that alternate. A fourth holds any class Toddle does not have, so its real name can be written in by hand.

Teacher allocation overview

Use this report to see each teacher’s estimated weekly allocation without manually counting timetable cards. Week A-only and Week B-only lessons count as 0.5 hours each in the average weekly total.

Subject and grade-level totals are derived from scheduled XML cards. Multi-class cards are counted once for teacher total time and proportionally split across grade/section breakdowns.

Secondary V4 with CP: key points, evidence and assumptions

This section summarises the main planning decisions, constraints and outstanding items behind the Secondary V4 timetable. Each key-point group includes a visual evidence block: either a live timetable snapshot drawn from the embedded data, or a clearly labelled planning diagram where the decision is not directly encoded in aSc.

Maths structure

  • Grade 6 Maths has been blocked with three classes running concurrently, allowing for two extended classes and four standard classes.
  • Grade 10 Maths will be streamable, although not all Maths lessons happen concurrently.
  • In Grade 10, Maths has been blocked against English to support the required grouping structure.

DP2 Maths changes

  • Two DP2 Maths AI HL classes have been created, reducing the original AI HL class of 21 into two smaller groups.
  • DP2 AA SL, which had one student, has been collapsed.
  • That student has been added to DP2 AA HL, and the class has been renamed DP2 AA MX.

Staff allocation and load controls

  • Allocations have been updated in consideration of recent POR allocations.
  • LTL SE allocations have been limited to 15 periods.
  • LTLC allocations have been limited to 16 periods.
  • Every effort has been made to reduce the number of preps and the spread of grade levels per teacher.
  • Where possible, teachers have been assigned primarily to Grades 6–8 or Grades 9–10.
  • Prior experience and preferences have been taken into account as far as possible.

DP1 subject demand and timetable block movement

  • DP1 Biology now requires three classes, rather than two as indicated by the first round of DP choices.
  • DP1 Global Politics now requires two classes, rather than one as indicated by the first round of DP choices.
  • To address this, one Biology class has been moved into Block C.
  • Global Politics has been moved into Block D.
  • This preserves the option for students to take three sciences.

Languages and MOE Arabic

  • Updated language choices have reduced the number of French B classes.
  • This should reduce pressure on the MEL team.
  • A number of Arabic A students have not chosen DP Arabic.
  • Those students will need to take MOE Arabic during lunch or after school because there is no seventh timetable block in the timetable.

MYP, ConnectEd and ToK

  • MYP PHE will take place as single periods, not doubles.
  • Grade 10 has a Week B slot for Moral Education or MYP Core / Personal Project, in addition to ConnectEd.
  • ConnectEd will take place each week for Grades 6–10 on Friday Period 1 for 30 minutes and Monday Period 4 for one hour.
  • ToK will also have 30 minutes on Friday morning and a further one-hour slot during the week.

V3 inclusion checks and still-provisional items

  • The CP/Careers Programme timetable is included in this V3 build through the Careers Program 1 class and CP-related subjects.
  • No classes are allocated double periods, including DP and PHE.
  • ToK teachers have not yet been assigned because the full candidate list is still awaited.
  • Department meetings are still being added. At present, only Maths, English and Science have been allocated a one-hour department meeting.
Note: the current department meeting allocation is a sequencing issue, not an indication of department prioritisation.
